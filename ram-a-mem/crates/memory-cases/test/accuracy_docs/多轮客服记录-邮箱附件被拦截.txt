多轮客服记录：邮箱附件被安全网关拦截

第一轮：
用户说供应商发来的报价单一直收不到，发件人截图显示发送成功。邮箱搜索不到主题，也不在垃圾箱。

第二轮：
管理员在 mail gateway 查到 quarantine event，命中策略 DLP-ENCRYPTED-ARCHIVE。附件名 quote_2026.zip，压缩包带密码，正文里没有项目编号。安全策略把它判定为未知来源加密压缩包。

第三轮：
用户改用 .rar 后仍然失败，因为策略识别的是 encrypted archive，不是具体扩展名。普通 PDF 附件可以正常进入收件箱。

处理建议：
让供应商改用公司批准的外部文件交换链接，并在邮件正文写明项目编号 APOLLO-42；如果必须临时放行，需要安全管理员按 message id 释放 quarantine，并补登记 DLP exception，有效期不能超过 24 小时。
