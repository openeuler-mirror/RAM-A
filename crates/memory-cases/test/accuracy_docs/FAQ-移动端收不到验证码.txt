FAQ 摘录：移动端登录收不到短信验证码

常见现象：
用户输入手机号后页面提示验证码已发送，但手机没有短信。重复点击发送后仍然没有收到，客服后台能看到 sms gateway 返回 delivered，用户端却没有弹窗。

排查记录：
1. 先确认手机号没有填错，账号国家区号和 SIM 卡归属地一致。
2. Android 机型重点检查短信拦截箱、骚扰拦截、1069 开头服务号黑名单，以及是否开启了夜间免打扰。
3. iOS 机型重点检查未知发件人过滤，双卡手机要确认验证码发到当前插着的那张 SIM。
4. 如果用户刚做过携号转网，短信通道路由可能还在缓存旧运营商信息。

推荐处理：
让用户把 1069 服务号移出黑名单，关闭短信拦截后重新发送；仍失败时切换语音验证码，并在客服后台把模板 ID SMS_LOGIN_OTP 加入白名单重发。携号转网用户需要提交运营商路由刷新工单。
