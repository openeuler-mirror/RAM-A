## 存储柜备份任务

| 项目 | 记录 |
| --- | --- |
| rsync error code 23 | NAS 备份只同步了部分文件 |
| 触发时间 | 每天凌晨 02:10 |
| 最近改动 | NFS 共享迁移到新存储池 |

### 后续处理

- 重新挂载 NFS 共享，确认挂载参数没有使用只读模式。
- 校验 UID/GID 权限映射，保证备份用户能读取项目目录。
- 排除 .tmp 临时目录，避免临时文件删除导致 rsync 中途返回 code 23。

```text
rsync error: some files/attrs were not transferred (code 23)
permission denied while reading /project/archive
```

复测时手动执行增量备份，NAS 任务状态从 partial 变为 success。
